## 数据建设入口

- 乐鑫芯片目录：https://www.espressif.com/en/products/socs
- 乐鑫产品选择器：https://products.espressif.com/zh/product-selector
- Rockchip 产品中心：https://www.rock-chips.com/a/cn/product/index.html
- RKNN Model Zoo：https://github.com/airockchip/rknn_model_zoo
- ESP-DL：https://github.com/espressif/esp-dl

上述链接用于发现资料，不是已完成采集、核验或获得全量供货确认的声明。覆盖率验收需要冻结日期、来源集合、型号与 SKU 清单，并列明未知项。演示数据永不计入正式覆盖率。

## 检索质量验收

建立含精确型号、近似型号、同义表达、中英文、算子属性、SDK 版本、来源冲突和无答案问题的工程师标注集。固定 k、服务器与并发条件，对比关键词基线和混合检索的 Recall@k、引用支持率、无答案处理、P95 时延和成本。真实数据与模型尚未完成该项验收。

## 部署前检查

使用随机密钥和独立密码，启用 HTTPS；备份 PostgreSQL 数据与文档卷并演练恢复。配置 Embedding 后导入真实文档完成一次解析、审核、发布、检索、更新与撤回的完整验证。自动化测试中的数值向量只用于验证数据库检索路径。
