# SOLEX 界面改版

## 已确认需求

- 基于当前原生部署版本 WeKnora v0.9.0 的完整源码维护；前后端、测试、文档与构建脚本一并导入本仓库 `weknora/`，不使用嵌套 Git 仓库、子模块或稀疏前端副本。
- 用户可见产品统一为 SOLEX，清理原产品名称、图标、宣传、官网/源码/社群跳转与相应嵌入页品牌。上游许可证和来源记录保留在源码。
- 用户已选择浅色科技风：冷白背景、石墨色文字、蓝绿色强调色。允许重构整个 UI，但继续使用现有账号、API 与知识业务。
- 先提交未经修改的上游源码基线，再单独提交界面与验收改动；保留之前未提交的其他项目改动。本轮仅本地 Git 提交，不自动推送或合并远端。

## 视觉方向

- 字标：SOLEX 大写字标，搭配简洁几何 S 图形；导航、登录、favicon 和移动端保持一致。
- 色彩：页面 `#f5f8f8`，面板 `#ffffff`，主文字 `#172d35`，次文字 `#667d85`，主色 `#087f8c`，选中背景 `#e5f4f2`，边框 `#dce7e7`。
- 字体：优先系统中文无衬线，清晰的字号与字重层级；不从外部字体服务加载资源。
- 布局：登录页采用品牌介绍与表单的双栏结构；工作台采用紧凑侧栏和宽内容区；窄屏保持导航、输入与主要操作可用。
- 细节：细边框、适量留白、轻阴影和一致圆角；提供明显焦点态、足够文字对比和减少动态效果的支持。

## 实现与验收范围

1. 登录、邀请/注册、账号菜单、侧栏、新对话和聊天界面。
2. 知识库、Wiki、智能体和设置的统一视觉基础。
3. 页面标题、favicon、空白状态、帮助/关于、分享/嵌入页、翻译文案及后端返回的内置产品名称。
4. 保留 API 字段、路由、存储键、第三方模型名称和用户资料原文，避免品牌替换破坏协议或修改企业资料。
5. 构建与适用测试通过；检查桌面/窄屏布局和主要页面，确认品牌与外链清理；Docker 仅替换前端镜像，保留后端与数据。

## Git 与上游

`origin` 继续指向 `PerLightFlow/select-chip-agent`；`weknora-upstream` 用于读取官方版本。原始源码基线提交记录确切上游 commit，后续定制均能与该基线比较。当前生产镜像保持不变，直到改版构建和验证完成。
