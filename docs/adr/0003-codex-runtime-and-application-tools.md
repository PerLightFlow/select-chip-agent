# 以 Chat Completions 为默认，保留 Codex 可选运行层

2026-10-29 的 Ark Responses 五项协议检查以及真实 Codex 动态工具调用通过，但完整调研在多次验收中超过 300 秒。同一模型和业务工具改用 Chat Completions 后，追问、调研、条件修正、项目问答分别以 23、163、19、42 秒完成。因此按 Q10 已确认的火山和体验优先原则，默认采用应用控制的 Chat Completions 工具循环；固定版本 Codex App Server 0.163.0 保留为显式可选运行层。两者共用业务权限、来源和确认流程，不自动切换提供方或协议。

应用负责账号、私有会话、需求摘要、项目知识、确认保存和后台任务。可选 Codex 每次使用独立临时运行目录，历史由应用按会话归属读取，不开放终端或用户文件环境。未 fork Codex，也未将其会话文件当作共享知识库。

调研工具将候选搜索与原文读取合并，缓存公开资料、限制网络并发并用编号引用来源。真实搜索发现部分引擎返回 HTTP 200 却没有型号相关性，因此默认选择验证有效的 google cse，精确查询型号并检查标题/URL 匹配，不能把普通 ESP32 资料当作 ESP32-P4 依据。官网失败时保留证据缺口。相关性回归测试先失败后通过。

工具可用、服务器健康及数据库合成检索通过，都不代表 50 人同时进行真实调研已达标。运行层和调研流程的最终验收仍以真实模型、搜索、来源及并发报告为依据；当前使用关键词全文检索，不将其表述为语义向量检索。
